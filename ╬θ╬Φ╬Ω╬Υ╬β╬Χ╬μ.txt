AUTO ΓΛΩΣΣΑ — ΚΥΡΙΟ SITE (taxiathenstransfers.com)
==================================================

ΤΙ ΚΑΝΕΙ
--------
Οποιοδηποτε link κι αν στειλεις (δικο σου, ξενο, με η χωρις γλωσσα), ο
παραληπτης προσγειωνεται στη ΓΛΩΣΣΑ ΤΟΥ BROWSER ΤΟΥ.

ΔΙΑΤΗΡΟΥΝΤΑΙ:
 • Η ΣΕΛΙΔΑ:  /no/booking  ->  /de/booking   (οχι στην αρχικη)
 • Το HASH:   #air+raf#hilton  (φιλτρο συνεργατη) — ακεραιο
 • Τα query params
 • Clean URLs του Cloudflare (/no/booking χωρις .html)

Αν ο browser δεν δινει αναγνωρισιμη γλωσσα, γινεται fallback σε geo-IP
μεσω Cloudflare (/cdn-cgi/trace).


⚠️ ΟΡΟΙ ΑΣΦΑΛΕΙΑΣ ΓΙΑ ΤΙΣ ΠΛΗΡΩΜΕΣ (ΣΗΜΑΝΤΙΚΟ)
-----------------------------------------------
ΔΕΝ γινεται ΠΟΤΕ redirect οταν:

1. Ο πελατης ΕΠΙΣΤΡΕΦΕΙ ΑΠΟ ΠΛΗΡΩΜΗ.
   Το Viva Source εχει ΣΤΑΘΕΡΟ success URL (booking.html). Αν γινοταν
   redirect εκεινη τη στιγμη, θα χανονταν τα query params της συναλλαγης
   και η ΚΡΑΤΗΣΗ ΔΕΝ ΘΑ ΕΠΙΒΕΒΑΙΩΝΟΤΑΝ ΠΟΤΕ.

   Παραμετροι που ενεργοποιουν το φρενο:
     Viva  : t, transactionId, TransactionId, eventId, EventId,
             s, orderCode, OrderCode
     Stripe: stripe_session_id

2. Υπαρχει εκκρεμης κρατηση στο sessionStorage
   (athenstaxi_pending_booking) — δευτερο διχτυ ασφαλειας.

3. Υπαρχει ?nolang στο URL — χειροκινητη παρακαμψη για δοκιμες.

4. Ο χρηστης εχει ηδη διαλεξει γλωσσα απο τον switcher σε αυτη τη
   συνεδρια. (Χωρις αυτο, μολις επελεγε γλωσσα θα τον γυριζε αμεσως
   πισω και ΔΕΝ θα μπορουσε ΠΟΤΕ να αλλαξει γλωσσα χειροκινητα.)


ΤΙ ΑΛΛΑΞΕ
---------
 • js/lang-redirect.js — ΑΝΤΙΚΑΤΑΣΤΑΘΗΚΕ πληρως.
   Το παλιο ετρεχε ΜΟΝΟ στην αρχικη (isRoot), δεν κρατουσε hash/params,
   και ηταν φορτωμενο μονο σε 4 αρχεια (ja, ru, hu, zh) οπου εβγαινε
   αμεσως — δηλαδη πρακτικα ΔΕΝ δουλευε πουθενα.

 • 238 HTML αρχεια — προστεθηκε <script src=".../js/lang-redirect.js">
   πριν το </head>, με σωστο relative path αναλογα με τον φακελο.


ΑΝΕΒΑΣΜΑ
--------
Τα αρχεια ειναι στη ΡΙΖΑ του zip, ακριβως οπως στο repo site-taxi.
Αντικατασταση ολων. Το Cloudflare Pages κανει build αυτοματα.


ΔΟΚΙΜΗ
------
1. Αλλαξε γλωσσα browser σε Γερμανικα.
2. taxiathenstransfers.com/booking          -> πρεπει /de/booking
3. taxiathenstransfers.com/el/booking#air+raf
   -> πρεπει /de/booking#air+raf   (ΤΟ HASH ΠΑΡΑΜΕΝΕΙ)
4. Με ?nolang -> ΔΕΝ πρεπει να αλλαξει.
5. ΚΡΙΣΙΜΟ: δοκιμαστικη πληρωμη 0,01 EUR — επιβεβαιωσε οτι μετα την
   επιστροφη απο τη Viva βλεπεις το μηνυμα επιτυχιας και ΔΕΝ σε
   μεταφερει αλλου.

Αν κατι παει στραβα, ?nolang σε καθε link = αμεση παρακαμψη.
